# /project — Documentación del Proyecto

Esta carpeta centraliza toda la documentación estratégica, operativa y técnica de **Padel Tracker IA**.  
No contiene código. No afecta el build ni el runtime.

---

## Índice de documentos

### `01_PRODUCT_BLUEPRINT.md`
Describe la visión completa del producto: qué es, a quién va dirigido, sus pilares de valor, el modelo de negocio y la hoja de ruta de alto nivel. Es el documento fundacional — responde "¿qué estamos construyendo y por qué?".

### `02_PMV.md`
Contiene únicamente las funcionalidades necesarias para lanzar la primera versión comercial. Define el alcance mínimo que entrega valor real y permite validar el negocio sin sobrecarga de features.

### `03_SPRINTS.md`
Contiene el estado de cada Sprint: objetivos, tareas comprometidas, avance y retrospectiva. Es el documento operativo del equipo semana a semana.

### `04_BACKLOG.md`
Ideas futuras y funcionalidades que NO forman parte del Sprint actual. Sirve como repositorio priorizado para planificar sprints futuros.

### `05_DECISIONS.md`
Registro histórico de decisiones de arquitectura y negocio (ADR — Architecture Decision Records). Documenta qué se decidió, por qué, y cuáles son las consecuencias conocidas.

### `06_CHANGELOG.md`
Registro cronológico de cambios importantes: nuevas funcionalidades, breaking changes, correcciones críticas y migraciones. Dirigido al equipo técnico y a stakeholders.

---

## Convenciones

- Los documentos se actualizan manualmente al cierre de cada sprint o al tomar una decisión relevante.
- El campo "Última actualización" de cada archivo debe reflejar la fecha real del último cambio.
- Ningún archivo de esta carpeta es procesado por el build ni importado por el código fuente.
